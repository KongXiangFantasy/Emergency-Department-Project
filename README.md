Discrete Event Simulation of Emergency Department Operations

A comprehensive simulation model built with SimPy to analyze and optimize emergency department (ED) patient flow and resource allocation. This project implements a priority queueing system based on the Manchester Triage Protocol, simulating patient arrivals, triage procedures, and treatment processes across multiple priority levels (Red, Orange, Yellow, Green, Blue).
Key Features:

Priority-based patient flow simulation using discrete event simulation
Manchester Triage Protocol implementation with five priority levels
Dynamic resource allocation modeling (doctors, nurses, treatment beds)
Statistical analysis with multiple simulation runs and 95% confidence intervals
Scenario testing for different resource configurations
Log-normal distribution fitting for triage and treatment times
Comprehensive performance metrics including waiting times, resource utilization, and system congestion

Technologies:

Python 3.x
SimPy (Discrete Event Simulation)
NumPy/SciPy (Statistical analysis)
Matplotlib (Visualization)

This simulation study demonstrates how varying ED resource configurations influence key performance indicators and provides actionable insights for optimizing staffing, managing patient flow, and improving overall emergency department efficiency.
